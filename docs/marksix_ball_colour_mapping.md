# 六合彩紅、藍、綠號碼球固定對照

本系統以香港賽馬會六合彩 50 週年官方資料所述的 **49 個號碼球分紅、藍、綠三色** 為依據；紅色 17 個，藍色與綠色各 16 個。[官方資料來源](https://campaigns.hkjc.com/2026-marksix/ch/funfacts)

| 球色 | 固定號碼 | 球數 |
|---|---|---:|
| 紅色 | 1, 2, 7, 8, 12, 13, 18, 19, 23, 24, 29, 30, 34, 35, 40, 45, 46 | 17 |
| 藍色 | 3, 4, 9, 10, 14, 15, 20, 25, 26, 31, 36, 37, 41, 42, 47, 48 | 16 |
| 綠色 | 5, 6, 11, 16, 17, 21, 22, 27, 28, 32, 33, 38, 39, 43, 44, 49 | 16 |

> 球色是號碼既定的展示分類，而不是會隨攪珠變動的訊號。本專案只把它作為描述性統計與介面呈現；不將其加入正式機率、四配置盲測、Brier 檢定或權重治理。
