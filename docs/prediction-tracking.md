# 預測紀錄與命中率追蹤

本專案會在 `updater.py` 成功以最新已知結果產生下一個目標期數的五組實驗性組合時，建立或保存 `data/prediction_history.json`。每筆紀錄包含目標期數、目標日期、產生時間、來源歷史資料範圍、融合模型設定及五組完整組合。目標期數已存在時，系統保留既有版本，而不會因為排程重跑而覆寫它。

Streamlit 的「命中率與回測分析」分頁會讀取這份版本紀錄及 `data/lotto_history_real.csv`。當目標期數已出現在真實歷史 CSV，系統以該期六個正選比對五組組合，個別顯示交集號碼、每組命中數、單期最高命中數及五組合計命中。尚未有正式結果的紀錄會保留為「待攪珠」，不會混入命中率統計。

頁面上的「平均每期最高命中」、「命中 3 個字或以上」及「五組合計平均命中」只用作回顧性模型監測。它們可協助評估 Random Forest／XGBoost 融合權重及 K-Means 特徵的歷史表現，但不能證明模型可預測未來攪珠結果。
